Entertainy — Sandbox Demo

This is the Entertainy website for TikTok Sandbox testing: https://msaqib3231860-ui.github.io/Entertainy/

Entertainy uploads the account owner's own videos to their own TikTok inbox as drafts. It does not publish automatically. The owner reviews and posts each draft themselves in the TikTok app.

Step 1 — Login with TikTok (Login Kit)

Scopes requested: user.info.basic and video.upload

Step 2 — Upload to TikTok inbox (Content Posting API, Upload)

Choose a video file from your device. This uses the inbox/draft upload flow, not Direct Post publishing.

For the Sandbox upload API call, paste a Sandbox user access token generated in the TikTok Developer Portal (the token is used only in your browser for this test, it is not stored on this site):
